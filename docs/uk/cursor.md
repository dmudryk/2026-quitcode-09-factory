# Якщо ви працюєте в Cursor

Коротко: **запускайте фабрику з Claude Code**, навіть якщо щодня пишете код у Cursor. Фабрика викликає агента сама, у
фоновому режимі (`claude -p` у робочому просторі), тож ваша IDE на результат не впливає. Писати тести, вимоги й адаптувати
імпортер можна в Cursor; запускати `F run` — з терміналу, де є нативний `claude.exe` і виконано вхід у Claude Code.

## Чому саме Claude Code

Лише для адаптера `claude` фабрика має повний захист і облік:

- **хук політики** вирішує кожен виклик інструмента: файли — лише в робочому просторі, захищені тести не редагуються,
  `**/.env*` не читається, команди — лише з дозволеного списку, без конвеєрів і ланцюжків;
- **ворота boundary** перевіряють, що хук справді вирішив кожен виклик;
- **вартість** кожного виклику записується в прогін і в proof pack, бюджет `runUsd` зупиняє прогін.

Цей адаптер перевірено реальними прогонами (upstream — жовтень 2026; курсовий спайк і демо-двійник — 02.11.2026 на
Next.js + Supabase).

## Адаптер `command` — НЕ перевірено

Для інших CLI фабрика має загальний адаптер `command`: бриф подається на stdin вказаної команди. Його можна спробувати з
Cursor CLI, але **ми його з Cursor не запускали**: не перевірено ні прапорці Cursor CLI, ні читання stdin, ні роботу в
нативному Windows. Наслідки, які відомі з коду фабрики:

- AI-політика мусить явно дозволити це: `"allowUnconfinedAgent": true` у `policy.json`;
- **хука немає** — інструменти агента нічим не обмежені, ворота boundary пропускаються;
- **вартість невідома** — прогін обмежують лише кількість спроб і час (`agentTimeoutMs`);
- кожен proof pack чесно пише «NO tool-level confinement».

Приклад (неперевірений) у `factory.json`:

```json
"agent": { "adapter": "command", "model": "cursor-agent", "command": ["C:\\path\\to\\cursor-agent.exe", "-p"] }
```

і `"cursor-agent"` у `approvedModels` політики. Якщо спробуєте — опишіть у звіті бонусу, що спрацювало, а що ні.

## Рекомендація

Для бонусу курсу: Claude Code для `F run`, Cursor — для всього іншого. Якщо Claude Code недоступний, бонус можна
виконати частково (двійник, імпортер, червоні тести, holdouts, `doctor`) і чесно описати, де зупинилися.
